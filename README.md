# ex-search

traQのメッセージ検索に、長めの履歴、ローカル検索候補、Tab補完、検索条件フォーム、検索語の強調、表示中ページの関連度順を追加するChrome / Edge向けManifest V3拡張です。

traQ APIやVue内部状態は使わず、traQが表示した検索画面だけを拡張します。

## インストール

### Chrome

1. `chrome://extensions` を開く
2. 「デベロッパーモード」を有効にする
3. 「パッケージ化されていない拡張機能を読み込む」を押す
4. この `ex-search` ディレクトリを選ぶ

### Edge

1. `edge://extensions` を開く
2. 「開発者モード」を有効にする
3. 「展開して読み込み」を押す
4. この `ex-search` ディレクトリを選ぶ

更新後は拡張機能一覧でex-searchを再読み込みし、既に開いているtraQのタブも再読み込みしてください。

## 使い方

traQでメッセージ検索を開くと、検索欄の下にex-searchパネルが表示されます。

- 検索候補: ex-searchの履歴、現在のチャンネルまたはユーザー画面、現在表示中の検索結果から最大8件を提示します。
- Tab補完: 入力の先頭に一致する候補がある場合、Tabキーで残りを入力します。
- 検索条件: 「全チャンネル / 現在のチャンネル」「任意 / 自分の投稿 / Bot / Bot以外」「任意 / 自分宛て」「添付種別」「日付」を日本語のフォームで指定します。関係のない自由語や未知の検索演算子は保持します。
- 強調表示: 検索語と一致する検索結果本文を文字列として安全に強調します。リンク、コード、入力欄は変更しません。
- 関連度順: パネルの「traQの順番 / 一致度順」で切り替えます。検索語の出現回数を使い、traQが現在描画している検索結果だけを安定して並べ替えます。

Escapeキーはex-searchの候補だけを隠し、traQ本来のキー操作は妨げません。Enterキーで通常どおり検索すると、そのクエリがex-searchの履歴へ追加されます。

## 設定

拡張機能の詳細画面から「拡張機能のオプション」を開きます。

- 履歴件数: 1〜100件、既定値20件
- 検索候補の有効・無効
- Tab補完の有効・無効
- 強調表示の有効・無効
- 既定の並び順: traQ標準 / 表示中ページの関連度順
- ex-search履歴の全消去

設定は `chrome.storage.sync`、検索クエリ履歴は `chrome.storage.local` に保存します。表示されたメッセージ本文や抽出した頻出語は保存しません。

## 制約

- 関連度順と表示中結果からの候補は、サーバー全体ではなくtraQが現在描画している1ページだけが対象です。
- サーバー全体のトレンド解析や追加検索リクエストは行いません。
- traQのDOM構造が大きく変更された場合、検索欄や結果を検出できなくなることがあります。その場合も広い範囲を推測して変更せず、機能が止まる側に倒します。
- 初版の対象originは `https://q.trap.jp` のみです。

## 権限とプライバシー

- `storage`: 設定と検索クエリ履歴の保存
- `https://q.trap.jp/*` のContent Script: 表示中の検索UIを拡張

ホスト権限、traQ APIアクセス、認証情報の読み取り、外部送信、ページ側JavaScriptへの注入は行いません。実行時の外部依存やビルド処理もありません。

## 開発とテスト

Node.js 18以降を使います。`jsdom` はテスト専用です。

```sh
npm install
npm test
npm run check
```

主な構成:

- `core.js`: 設定、履歴、検索条件、候補、補完の純粋ロジック
- `dom.js`: 検索欄・結果の検出、強調表示、表示中結果の並び順
- `app.js` / `content.js`: ストレージとtraQ SPAへの組み込み
- `options.html` / `options.css` / `options.js`: 設定画面
- `memo.md`: 元になったアイデアメモ
